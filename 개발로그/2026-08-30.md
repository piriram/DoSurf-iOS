## 왜

이 저장소에는 `develop`이 없어서 작업 브랜치가 곧바로 `main`을 향하고 있었다.
`main`은 릴리즈/안정 브랜치여야 하는데 기능 PR이 그리로 가면 그 구분이 사라진다.
백엔드(DoSurf-API)는 이미 `develop`을 쓰고 있어서 기준도 맞지 않았다.

PR 푸터는 구직 중이라 저장소가 포트폴리오로 읽히는 상황에서 작업 주체를
흐린다. 커밋 메시지에는 원래 안 넣고 있었는데 PR 본문에는 들어가 있었다.

## 어떻게

`develop`을 `main`과 같은 지점에서 만들고 PR base를 옮겼다. 앞으로 기능
브랜치는 `develop`으로 PR하고, `main`은 릴리즈 시점에만 받는다.

전역 공통 규칙(`~/shared/docs/agents-common.md`)에 두 가지를 넣었다.
- AI 흔적 금지 범위를 커밋뿐 아니라 **PR 제목·본문·브랜치명까지** 확장
- **PR 대상은 `develop`**. 없는 저장소면 만들 것인지 먼저 확인하고,
  임의로 `main`에 PR하지 않는다

백엔드 저장소는 커밋 메시지에도 AI 트레일러가 남아 있어 히스토리를 다시 쌓았다.
이 저장소는 확인 결과 **커밋 히스토리가 깨끗해서** 손대지 않았다.

```
git log --all --grep="Co-Authored-By: Claude" -i   → 결과 없음
```

## 배운 점 / 다음 액션

**PR은 커밋과 다른 경로로 새어나간다.** 커밋 메시지 규칙은 지키고 있었는데
PR 본문에는 도구 푸터가 기본값으로 들어갔다. 규칙을 "커밋에 넣지 마라"로만
적어두면 이런 구멍이 생긴다. 그래서 규칙 문구를 매체가 아니라 대상 기준으로
다시 썼다 — 커밋·PR·브랜치명 전부.

## 세션 2 — P4 데이터 출처 표기

### 무엇을

"내가 선호하는 차트 통계" 안내 시트(ⓘ 버튼) 맨 아래에 데이터 출처를 넣었다.
넣는 과정에서 그 시트에 **배경이 없었다는 것**을 발견해 같이 고쳤다.

### 왜

Open-Meteo 무료 티어는 CC BY 4.0이라 출처 표기가 의무인데 앱 어디에도 없었다.
코드 문제가 아니라 라이선스 문제여서 미룰 성격이 아니었다.

### 어떻게

**자리 선정.** 이 앱에는 설정이나 정보 화면이 따로 없다. 처음에는 대시보드
`PreferredPage`의 카드 아래에 붙였는데 아니었다. 거기는 페이지 캐러셀 안이라
넘기면 사라지고, 매번 보이는 자리라 밀도를 해친다.

ⓘ 버튼으로 열리는 안내 시트가 맞았다. 이미 "이 값이 어디서 오는지"를 설명하는
자리라 출처가 붙을 맥락이 있다.

기상청도 함께 적었다. 파고 우선순위를 Open-Meteo로 뒤집었지만 바람·기온 등은
여전히 기상청 값이다.

**딸려 나온 버그.** 라벨을 넣으니 그 아래로 대시보드가 비쳐 보였다.
원인은 시트에 배경이 없었다는 것이다. 흰 배경으로 보이던 것은 `sheetImageView`의
이미지였고, 이미지가 끝나는 지점부터는 아무것도 칠하지 않고 있었다. 그 아래에
내용이 없었을 뿐이라 지금까지 드러나지 않았다.

`view.backgroundColor = .systemBackground`가 이미 있었는데도 그랬다.
**iOS 26 시트는 반투명 재질을 써서 시맨틱 배경색이 그대로 비친다.**
불투명 값을 직접 지정한 배경 뷰를 맨 뒤에 깔아 해결했다. 다크모드는 조건부
색으로 대응했다.

시뮬레이터에서 시트를 열어 스크린샷으로 확인했다. 하단 영역을 잘라 확대해
보기 전까지는 비침이 잘 안 보였다.

### 배운 점 / 다음 액션

**빈 공간은 버그를 숨긴다.** 배경이 없는 채로 몇 달을 지냈는데, 그 자리에
아무것도 없어서 아무도 몰랐다. 요소 하나를 추가하는 일이 기존 결함을 드러낸
셈이다 — 내가 만든 버그처럼 보이지만 아니었다.

**시맨틱 색이 항상 불투명한 것은 아니다.** `.systemBackground`를 "흰색"으로
읽고 있었는데, 표시 맥락(iOS 26 시트)에 따라 반투명하게 합성된다. 배경을
확실히 칠해야 하는 자리에서는 값을 직접 지정하는 편이 안전하다.

**라벨에 "지우지 말 것 — 라이선스 조건" 주석을 달았다.** 화면 정리하다가 작은
회색 글씨부터 지우기 쉽다.
